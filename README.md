# 🎧 Vinylz

**Vinylz** é uma rede social musical brasileira inspirada em experiências como Letterboxd, Spotify e Twitter/X, feita para usuários descobrirem músicas, favoritar artistas/álbuns/faixas, publicar reviews e interagir com outros fãs.

O objetivo do projeto é criar um espaço social moderno, visualmente premium e focado em música, com integração ao Spotify e Firebase.

---

## 🚀 Funcionalidades

- Autenticação de usuários com Firebase
- Cadastro e login
- Perfil de usuário
- Edição de perfil
- Banner e foto de perfil
- Catálogo musical com busca
- Integração com Spotify
- Página de detalhes de artistas, álbuns e músicas
- Sistema de favoritos
- Timeline/social feed
- Posts, curtidas, respostas e reposts
- Sistema de seguir usuários
- Notificações
- Perfil público
- Onboarding musical
- Compatibilidade/charts com dados do Spotify
- Interface dark premium responsiva
